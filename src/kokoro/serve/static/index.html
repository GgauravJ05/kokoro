    Searching…

    This is a research demo, and it is wrong sometimes. The model learns mood from review prose with no popularity prior, which is good for catalog coverage and hard on a demo — so “well-known titles only” applies a serving-side audience floor. That filter is deliberately absent from every reported metric. On the evaluation that matters, cold-start retrieval over titles with zero interaction history, this scores 0.0845 NDCG@10 where every collaborative baseline scores exactly 0.0000.
