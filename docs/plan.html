Thesis

Why this isn't another cosine-similarity demo

The standard version of this project — scrape MyAnimeList, TF-IDF the synopses, cosine similarity, ship a Streamlit app — exists on thousands of resumes. A reviewer identifies it in ten seconds. Kokoro is built around two claims that are hard to make and harder to fake.

One. Genre tags cannot express mood. Drama contains both Violet Evergarden and School Days. The signal has to be learned from how viewers actually write about what a show did to them.

Two. A title is not one point in taste space. Every deployed recommender treats it as one, and that is why none of them can answer “starts light, gets devastating.”

Figure

The failure a single mood vector hides

Three shows, plotted on the comfort axis across their runtime. All three average out to roughly the same place. A point-based model calls them interchangeable; a viewer would never confuse them.

Method

Three components, each independently ablatable

  • Two-tower contrastive retriever. Untied query and item encoders trained with InfoNCE on (review sentence → title) pairs. Hard negatives are mined from the same genre — a random negative for Violet Evergarden is some sports comedy the model separates trivially.
  • Anchored mood bottleneck. The item tower routes through eight named bipolar axes, so every recommendation ships an explanation instead of a similarity score. An anchor-alignment loss is what makes the axes mean what they are named; without it they are an arbitrary rotation and the interpretability claim is false.
  • Trajectory encoder. Review sentences are bound to the arc they discuss, giving a curve of shape (n_arcs, n_axes) per title. A dilated 1-D CNN reads local turns; its contribution is gated by a learned scalar initialised at zero, so it only enters the embedding if it earns loss.

Evidence

The evaluation contract, fixed before the models

A harness written after the model it evaluates grows whatever affordance makes that model look good. This one was written first and is already passing tests. Two metric families are reported, and the second is treated as equally load-bearing: a recommender can top the accuracy table by showing the same fifty popular titles to everyone, which is the known failure mode on a catalog this long-tailed.

Baselines that must be beaten: random, popularity, item-kNN, BM25 on synopsis, off-the-shelf embedding similarity, and a raw LLM prompt. That last one is the real bar — if asking a frontier model directly does as well, the project has no reason to exist. The design targets where it wins: latency, cost per query, catalog coverage, calibrated axes, and titles too new or obscure to have been memorised.

Roadmap

Nine weeks

Ordering is deliberate. Data first because it is 40% of the work and everything downstream is blocked on it; the writeup last but budgeted, because it is what admissions committees actually read.

1–2

Corpus ✓

AniList + Jikan ingestion at scale, dedup, spoiler filtering, arc/episode alignment. Freeze a versioned dataset and never quietly change it again.

3

Baselines ✓

Run the existing harness against the frozen corpus. Add BM25 and the off-the-shelf-embedding baseline. This is the table everything is measured against.

4–5

Two-tower training ✓

InfoNCE with mined hard negatives. Ablate: negative strategy, batch size as a modelling parameter, tied vs untied towers, bottleneck width.

6

Axis validation — partial

Collect ~200 human mood judgements; report Spearman ρ per axis. An axis that does not correlate gets reported as such, not quietly dropped.

7

Trajectory model — falsified

Curves built for 140 titles, then tested against a permutation control. Real curves move 1.15× more than shuffled ones, so a signal exists — but shape-only prediction is at chance and adding shape degrades a mean-only model. The neural encoder was deliberately never trained: fitting more parameters to a signal that fails its control is fitting noise.

8

Serving ✓

FastAPI + HNSW, quantised export, recall-versus-latency sweep on ef_search, p95 budget under 100 ms. Deploy on a free tier.

9

Writeup ✓

README with the full ablation table and plots, plus a short arXiv-style PDF. Target a workshop late-breaking-results track — even a rejection is a legitimate line, and the reviews are free feedback.

Actual bullet — every figure measured

Kokoro — Mood-Conditioned Cold-Start Retrieval. Trained a two-tower contrastive retriever (InfoNCE) over 52.5k user reviews so that titles with zero interaction history remain rankable — where every collaborative baseline scores exactly 0.0000 NDCG@10, this reaches 0.0845 (4.97× random, +41% over an off-the-shelf encoder on an identical frozen backbone), served at 4.4 ms p95. Reported a falsified trajectory hypothesis with a permutation control. [repo] [paper]

The trajectory idea was executed, not mentioned — and it failed. That is the honest version of the bullet, and it is the stronger interview story: a falsifiable test of one's own central hypothesis, properly controlled, reported when it came out negative.
